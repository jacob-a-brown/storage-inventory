# storage-inventory
A web app to inventory what is in storage

# Backend

## Virtual Environment
To set up a virtual environment run

```bash
python -m venv venv
```

To enter the virtual environment run

```bash
source venv/bin/activate
```

on macOS or

```bash
source  venv/Scripts/activate
```

on Windows.

## Dependencies

Requires `Python 3.14.2`. To install dependencies run

```bash
pip install -r requirements.txt
```

after entering the virtual environment.
